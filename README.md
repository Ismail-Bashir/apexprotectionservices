# Apex Protection Services

Website for Apex Protection Services, a security company in Toronto and the GTA.

Built with Next.js 16, React 19 and Tailwind CSS 4.

## Running it locally

```bash
npm install
npm run dev        # http://localhost:3000
```

`npm run build` exports the static site to `out/`, and `npm run lint` checks the code.

## Deployment

The site is hosted on GitHub Pages at `https://apexprotectionservices.ca` (set under **Settings → Pages → Custom domain**; `www` redirects to it). Every push to `main` runs `.github/workflows/deploy.yml`, which builds the static site and publishes it. The workflow reads the base path and site URL from the Pages settings, so changing the domain there needs only a re-run of the workflow.

## Before launch

1. **Contact details.** The phone number, email and domain in `src/lib/site.ts` are placeholders. Replace them with the real ones.
2. **Form delivery.** The quote and job application forms send email through [Web3Forms](https://web3forms.com) directly from the browser. Create an access key for the inbox that should receive submissions, then add it as a repository secret named `WEB3FORMS_KEY` (**Settings → Secrets and variables → Actions**) and redeploy. Until the key is set, the forms show an error asking visitors to call.
3. **Claims.** Check that the claims on the site are accurate for the business, and edit them if not. They include PSISA-licensed guards, 24/7 dispatch, "fully insured", digital shift reports and field supervisors. They appear in `src/lib/site.ts`, `src/lib/faq.ts`, `src/app/page.tsx` and `src/app/about/page.tsx`.

## Where things live

| What | Where |
| --- | --- |
| Company details, service areas | `src/lib/site.ts` |
| Services, with copy for each service page | `src/lib/services.ts` |
| FAQ | `src/lib/faq.ts` |
| Careers roles, requirements, perks | `src/lib/careers.ts` |
| Pages | `src/app/` |
| Quote and application forms | `src/components/forms.tsx` |
| Deploy workflow | `.github/workflows/deploy.yml` |

To add or remove a service, edit `SERVICES` in `src/lib/services.ts`. The home page, services page, footer, contact form, sitemap and individual service page all update from that list.

Images in `public/` must be referenced through `asset()` from `src/lib/site.ts`, so they get the GitHub Pages base path.

## Illustrations

The images in `public/images` are original SVG illustrations generated by `scripts/generate-art.mjs`. To change one, edit the script and run `npm run art`. If you have real photos of your guards, sites or vehicles, use them in place of the illustrations. Real photos build more trust.
